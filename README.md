# Learning AI/ML

This repository documents my learning journey in Artificial Intelligence (AI) and Machine Learning (ML). It serves as a record of the concepts I study, the code I write, and the practical exercises I complete as I develop my understanding of AI/ML.

## 1.1 Overview of Machine Learning

- **Introduction to Machine Learning:** Learned what machine learning is and how it enables computers to learn from data to make predictions or decisions.
- **Applications of Machine Learning:** Explored how machine learning is applied in areas such as recommendation systems, image recognition, speech recognition, and other real-world problems.

## 1.2 Supervised vs. Unsupervised Machine Learning

- **Supervised Learning:** Learned how algorithms use labeled data to map inputs to outputs, including its two major types: regression and classification.
- **Unsupervised Learning:** Learned how algorithms discover patterns and structures in unlabeled data through techniques such as clustering, anomaly detection, and dimensionality reduction.

[View Notes](./1.2%20Supervised%20vs.%20Unsupervised%20Machine%20Learning/)

## 1.3 Regression Model

- **Linear Regression Model:** Learned how linear regression uses a straight line to predict numerical values, including how input features, target values, and training examples are represented in a training set.
- **Cost Function:** Learned how the cost function measures the prediction errors of a linear regression model using squared errors.
- **Cost Function Intuition:** Explored how different values of the model parameter affect the cost and how the cost function helps identify better-fitting models.
- **Visualizing the Cost Function:** Learned how three-dimensional surface plots and contour plots represent the cost function and help visualize its minimum.
- **Visualization Examples:** Compared different parameter values to understand how the prediction line's fit relates to its corresponding cost.
